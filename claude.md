# CLAUDE.md

## Project

Local research agent: FastAPI backend calls Ollama with a `web_search` tool, streams
NDJSON progress events to a React frontend. Everything runs on this machine — no cloud
API, no Docker.

Two halves, no monorepo tooling between them: `backend/` (Python) and `frontend/` (pnpm).

## Commands (exact)

Backend, from `backend/`:

- Install: `.venv\Scripts\python.exe -m pip install -r requirements.txt`
- Dev: `.venv\Scripts\uvicorn.exe main:app --reload --port 8000 --env-file .env`
- Test: `.venv\Scripts\python.exe test_stream.py` — prints `ok`, no pytest, no network

Frontend, from `frontend/`:

- Install: `pnpm install`
- Dev: `pnpm dev` — Vite on port 5173, the only origin the backend's CORS allows
- Test: `pnpm test` — runs `test-health.mjs` and `test-history.mjs` under plain node
- Build: `pnpm build`

No linter and no formatter is configured. Do not add one.

Ollama must be running separately with a tool-calling model pulled: `ollama pull qwen3:8b`.
`GET /api/health` reports whether it is reachable and whether the model is present.

## Where to look

- Agent loop, search, and the three hallucination checks: `backend/main.py`
- Turn rendering and the NDJSON reader: `frontend/App.jsx`
- Pure logic worth testing, kept out of components: `frontend/lib/health.js`,
  `frontend/lib/history.js`
- Vendored shadcn registry components: `frontend/components/ui/`

## Conventions

- Tests are `assert`-based self-check scripts, one file per unit, no framework and no
  fixtures. New logic extends an existing script rather than adding a runner.
- Every non-obvious constant and branch carries a comment saying *why*, not what. Match
  that density; it is the house style, not decoration.
- Deliberate shortcuts with a known ceiling are marked `ponytail:` naming the ceiling and
  the upgrade path.
- Branches: `feat/`, `fix/`, `refactor/`, `chore/`. Commit subjects are lowercase
  imperative, `type: what changed`.
- Backend is `async` throughout; anything blocking goes through `asyncio.to_thread`
  (see `search_blocking`).

## Limits: DO NOT TOUCH

- `backend/.env` — real local config, gitignored. Edit `.env.example` instead.
- `frontend/pnpm-lock.yaml` — never hand-edit; change it only via a `pnpm` command.
- `frontend/components/ui/` — generated by the shadcn CLI. Edits are lost on the next
  `shadcn add`. Wrap them from the outside instead.

## Claude-specific

- Answer-quality changes touch three coupled checks in `backend/main.py`
  (`unretrieved_urls`, `unsupported_citations`, `ungrounded_names`) and their three
  banners in `frontend/App.jsx`. Change all of them or none.
- Never let internal row flags (`dead`, `status`) reach the model's context — the tool
  payload is whitelisted by key on purpose, and `test_stream.py` asserts it.
- After backend edits: `.venv\Scripts\python.exe test_stream.py`. After frontend logic
  edits: `pnpm test`. Component and layout changes have no test — verify in the browser.
- `pnpm build` catches nothing at runtime here; a broken stream only shows up with Ollama
  actually running.
